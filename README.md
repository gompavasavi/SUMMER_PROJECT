# Summer Project

This repository contains the research projects I completed during my Summer Internship.

## Projects

### 1. WriterINet
Implementation of the research paper:

**WriterINet: A Multi-Path Deep CNN for Offline Text-Independent Writer Identification**

**Highlights**
- PyTorch
- DenseNet201
- ResNet50
- Artificial Neural Network (ANN)
- IAM Handwriting Dataset

---

### 2. DT2F-TLNet

Implementation of the research paper:

**DT2F-TLNet: A Novel Text-Independent Writer Identification and Verification Model using Deep Type-2 Fuzzy Architecture and Transfer Learning Networks**

**Highlights**
- TensorFlow / Keras
- InceptionV3
- Type-2 Fuzzy CNN
- CEDAR Signature Dataset
